# @podmates/mobile

Expo SDK 58 app. Run it from the repo root after the backend is up (see the root README):

```bash
cd apps/mobile && npx expo start     # press i for the iOS Simulator (Expo Go)
```

- `npm run typecheck` / `npm test` (vitest, pure TS only) / `npm run lint`
- Local deep links: `exp://127.0.0.1:8081/--/sign-in?demo=maya` signs in as a demo user (local only).
